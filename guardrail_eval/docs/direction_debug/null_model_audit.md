# §2·§3 — shuffle-null 재검증

## 결론: 이전 설명("공통 평균 때문")은 **틀렸다**

`delta = mean(A) - mean(B)` 에서 전체 공통 평균은 **원칙적으로 상쇄된다.**
따라서 높은 귀무 cosine 을 "공통 평균 방향 공유"로 설명한 것은 오답이다.

진짜 원인은 **공분산 비등방성 / 극단적으로 낮은 유효차원**이다.

## 증거 1 — 이동벡터가 사는 공간의 유효 랭크

`r_eff = (tr Σ)² / tr(Σ²)`, 차원은 768. TRAIN 에서만 적합.

| 전이 | WildJailbreak top1 | r_eff | JOT top1 | r_eff |
|---|---:|---:|---:|---:|
| L1→L2 | 0.574 | 2.43 | 0.701 | 1.91 |
| L5→L6 | 0.690 | 2.05 | 0.593 | 2.61 |
| L7→L8 | 0.347 | 7.06 | 0.534 | 2.99 |
| **L8→L9** | 0.262 | **11.42** | 0.531 | 2.86 |
| L10→L11 | 0.753 | 1.74 | 0.897 | 1.24 |
| L11→L12 | 0.826 | 1.45 | **0.911** | **1.20** |

**768차원 공간인데 유효 랭크가 1.2~11.4다.** 상위 1개 주성분이 분산의 26~91%를 설명한다.
방향을 고를 자유도가 사실상 1~11개뿐이므로, 라벨을 아무렇게나 섞어 만든 두 평균차 방향도
거의 강제로 정렬(또는 반정렬)된다.

## 증거 2 — 유효 랭크와 귀무 cosine 의 대응

WildJailbreak 층별로:

| 전이 | r_eff | 귀무 \|cos\| |
|---|---:|---:|
| L8→L9 | 11.42 | 0.226 (최저) |
| L7→L8 | 7.06 | 0.252 |
| L9→L10 | 5.77 | 0.298 |
| L1→L2 | 2.43 | 0.530 |
| L11→L12 | **1.45** | **0.676 (최고)** |

**spearman(r_eff, 귀무|cos|) = −0.927**, **pearson(1/r_eff, 귀무|cos|) = +0.907**.
유효 랭크가 귀무 cosine 을 거의 전부 설명한다.

## 이번 단계의 치환 귀무 설계

- 이론값 `1/sqrt(768) ≈ 0.036` **사용 안 함**
- `cos(delta_U, delta_S)`: **예측 가지를 보존**한 채 정오 라벨만 섞음. **N = 10,000**
  → 최소 도달 p = 1/(10001) = **9.999e-05**
- cross-dataset cos: cell 라벨 전체를 개수 보존해 섞음. **N = 5,000**
  → 최소 도달 p = 1/5001 = **2.00e-04**
- **부호 있는(signed) 분포를 저장**한다. 정렬(+)과 반정렬(−)은 전혀 다른 결과이므로
  절대값만 쓰지 않는다. `signed_p` 와 `two_sided_p` 를 모두 보고한다.
- **p < 1e-5 는 주장하지 않는다** — Monte-Carlo 로 도달 불가능한 값이다.
  (이전 단계에서 "치환 p < 1e-5" 라고 적은 것은 N=20,000 기준 최소 4.999e-05 이므로
  `p < 5e-05` 로 고쳐 읽어야 한다.)
