# 방향성 신호 검증 결과 (Directional Signal Verification)

검증 질문: **"DecompX 기반 층별 방향성 신호가 정탐(TP)과 오탐(FP) 사이에 실제로 존재하는가?"**

이 단계에서는 검증기(verifier)를 설계·학습하지 않았고, 증류·점수 혼합·최종 cascade 도 하지 않았다.
PG2 확률/로짓은 confusion cell(TP/FP) 을 만드는 hard prediction 용도 외에는 방향 특징으로 쓰지 않았다.

기호 (지시문 18절 — 절대 섞지 않는다):

| 기호 | 정의 |
|---|---|
| `C_k^(l)` | 층 l **최종 인코더 분해**(post-LN2)의 CLS 행, 원천토큰 k 기여 벡터 |
| `D_k^(l)` | `C_k^(l) - C_k^(l-1)` — Token Contribution Shift |
| `g^(l)` | `h_CLS^(l) - h_CLS^(l-1)` — 실제 CLS 이동 (일반 은닉표현에서 직접) |
| `v_U^(l)` | ver_train TP-FP **평균차 단위 방향** |
| `p^(l)` | `dot(v,g)` 전역 사영 |
| `q^(l)` | `p - tau` (중심 중점 기준 좌표) |
| `a_k^(l)` | `dot(v_U^(l), D_k^(l))` — Directional Token Contribution Shift |

## A. 기존 추출물 유효성

**기존 6,142표본 추출물이 층별 `C_k^(l)` 를 포함했는가 — NO. 재추출 필요했고, 수행했다.**

기존 `decompx_*.pt` 는 `C^(12) - C^(1)` 하나로 접힌 `delta_c` 만 저장했고
(추가로 분류기 귀속 `margin` — 이번 실험 금지 목록), 층별 `C_k^(l)` 이 없었다.
상세는 `docs/directional_signal_extraction_audit.md`.

재사용한 것: `hidden_{split}.pt` 의 층별 CLS 은닉표현 `(n,13,768)`.
덕분에 `g^(l)` 와 `v_U^(l)` 는 재추출 없이 확정했고, 재추출 때는 `v_U` 를 이미 알고 있으므로
`a_k^(l)` 를 추출 시점에 바로 계산해 저장량을 58 GB → 수백 MB 로 줄였다.

**전제 검증** (`src/directional/verify_layer_semantics.py`):
분류 대상 위치 = 색인 0 = `[CLS]`(id=1), `ContextPooler` 가 `hidden_states[:,0]` 사용 — 소스로 확인.
`hidden_states[0]`=임베딩, `[12]`=최종층 — 실측 차이 `0.000e+00`.
패딩 기여 노름 = `0.000e+00` 이라 "전체 위치 합" == "유효 토큰 합".

## D. ★ 같은 출처 통제 — 이 결과의 정체

### D-1. `v_U` 는 말뭉치 방향과 **같은 방향**이다

TP/FP 라벨을 **전혀 쓰지 않고** 출처(탈옥 말뭉치 vs WildChat)만으로 만든 방향
`v_S^(l) = normalize(mean(g|탈옥) - mean(g|wildchat))` 와의 각도:

| 전이 | cos(v_U, v_S) | 각도 |
|---|---:|---:|
| L1->L2 | 0.9999922597 | 0.225° |
| L2->L3 | 0.9999804584 | 0.358° |
| L8->L9 | 0.9999939359 | 0.200° |
| L9->L10 | 0.9999947930 | 0.185° |
| L10->L11 | 0.9999993724 | 0.064° |
| L11->L12 | 0.9999996176 | 0.050° |

768차원에서 **0.05°~0.36°**. 두 방향은 사실상 동일하다.

같은 `q` 로 '출처(wildchat 여부)'를 맞히는 AUROC 도 TP/FP 를 맞히는 것과 거의 같다
(`eval_test` L8->L9: TP/FP 0.9799 vs 출처 0.9685, 차이 0.011).

### D-2. 같은 출처 내부 검정은 가능했지만 **한쪽 셀이 매우 작다**

출처별 TP/FP 표본 수:

| 분할 | jailbreak_chat | jailbreak_llms | wildchat |
|---|---|---|---|
| ver_train | TP 1683 / **FP 0** | TP 503 / **FP 0** | TP 21 / FP 1380 |
| ver_dev | TP 423 / FP 0 | TP 117 / FP 0 | TP 11 / FP 337 |
| eval_val | TP 261 / FP 0 | TP 72 / FP 0 | TP 8 / FP 212 |
| eval_test | TP 536 / FP 0 | TP 139 / FP 0 | TP 9 / FP 430 |

탈옥 말뭉치에는 **오탐이 하나도 없다.** 같은 출처 방향을 만들 수 있는 곳은 WildChat 뿐이고,
그 안의 TP 는 학습 21건 / held-out 28건(3분할 합산)뿐이다. 억지로 다른 출처 방향을 만들지 않았다.

**WildChat 내부 (held-out 3분할 합산, TP 28 / FP 979), 방향은 ver_train WildChat 에서만 적합.**
표본이 작아 부트스트랩은 신뢰할 수 없으므로 **치환검정(20,000회)** 을 썼다:

| 전이 | AUROC | 치환 p | 귀무 95% |
|---|---:|---:|---|
| L1->L2 | 0.9301 | <1e-5 | [0.392, 0.609] |
| L7->L8 | 0.9495 | <1e-5 | [0.391, 0.607] |
| **L8->L9** | **0.9766** | <1e-5 | [0.392, 0.608] |
| **L9->L10** | **0.9770** | <1e-5 | [0.393, 0.609] |
| L11->L12 | 0.9498 | <1e-5 | [0.392, 0.607] |

**즉 말뭉치 교란을 제거해도 분리는 남는다.**

### D-3. 그러나 그 분리는 WildChat 고유가 아니다 — 가짜 방향 대조

학습 WildChat TP 21건 대신, **전역 TP 풀에서 무작위로 21건**(대부분 탈옥 말뭉치)을 뽑아
같은 절차로 만든 '가짜 방향'으로 같은 WildChat held-out 을 평가했다 (30회 반복):

| 전이 | 진짜 WildChat 방향 | 가짜 방향 평균±표준편차 |
|---|---:|---:|
| L7->L8 | 0.9495 | 0.9432 ± 0.0060 |
| L8->L9 | 0.9766 | 0.9757 ± 0.0014 |
| L9->L10 | 0.9770 | 0.9767 ± 0.0082 |

**차이가 없다.** WildChat 내부 정탐/오탐을 가르는 데 WildChat 전용 방향이 필요하지 않다.
"탈옥 말뭉치 쪽을 가리키는 아무 방향"이면 똑같이 갈린다.

**Q5 = 분리는 유지되나, WildChat 고유 신호는 아니다.**
**Q8 = 전역 평가는 출처로 완전히 설명된다(0.05°). 같은 출처 내부 분리는 출처로 설명되지 않지만,
"탈옥체(攻擊體) 유사도" 축과 구별할 수 없고 held-out TP 가 28건뿐이다.**

### F. ★ 이전 분석과의 비교 — 서로 다른 신호다

| | 이전: UNSAFE-margin 귀속 | 이번: Directional Contribution Shift |
|---|---|---|
| 대상 | `A[k,UNSAFE] - A[k,BENIGN]` (분류기 로짓) | `a_k^(l) = dot(v_U^(l), D_k^(l))` (층별 인코더 분해) |
| 상위 토큰의 구두점 비율 | **TP 86.2% / FP 86.4%** — 거의 동일, 무정보 | **층마다 크게 다르고 TP/FP 도 다르다** (아래) |

| 전이 | TP 구두점 / 내용어 | FP 구두점 / 내용어 |
|---|---|---|
| L2->L3 | 46.5% / 40.0% | **19.2% / 69.6%** |
| L4->L5 | 43.7% / 39.4% | 30.5% / 49.9% |
