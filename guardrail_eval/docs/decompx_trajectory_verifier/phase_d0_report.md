## 13. normalization diagnostic — **실행하지 않음 (gate 미충족)**
§13 조건은 두 가지 접속이다.
(a) source 간 C norm 차이가 크다 → **충족**(9~12층 SMD 최대 1.47).
(b) source probe accuracy 가 그와 함께 증가한다 → **불충족**.
   probe macro-F1 은 norm 이 동일한 1층에서 이미 0.981 이고 12층에서 0.980 으로 평평하다.

따라서 자동 실행하지 않았다.  다만 (a)가 성립하고 그 층이 정확히 occlusion 이 작동하는
9~12층이므로, N1/N2 는 다음 단계의 **1순위 후보**로 남긴다(§16 참조).

## 14. ROOT-CAUSE TAXONOMY 판정

**R7 — MULTIPLE CAUSES**, 구체적으로 **R3 + R4**가 주 원인이고 **R2 가 이를 뒷받침**한다.

| 코드 | 판정 | 근거 |
|---|---|---|
| R1 source encoding dominates | **부분 성립** | 라벨 통제 probe 0.98/0.88.  단 A3 내부(0.93/0.81)는 오히려 **낮아** "인코더가 강화한다"는 조건은 불충족 |
| R2 error geometry is source-dependent | **성립** | 층별 코사인이 −0.58~+0.88 로 흩어지고, ‖d_s‖ 가 source 간 3~8배 차이 |
| R3 trajectory branch overrides stable attribution | **성립** | trajectory=0 에서 LOSO PS +0.485 / QS +0.140 회복, attribution=0 에서는 악화 |
| R4 specific depth region causes shift | **성립** | 1~8층 영향 0, 9~12층 블록 제거로 LOSO 3 fold 평균 +0.243 |
| R5 magnitude / scale shortcut | **미확정** | norm 차이는 9~12층에 실재하나 normalization diagnostic 을 아직 돌리지 않았다 |
| R6 WildJailbreak negative transfer | **기각** | A3 비대각 최악은 QS→PS(0.218), WJ 학습이 오히려 가장 낫다 |
| R8 unresolved | 해당 없음 | |

## 15. 가장 강한 증거 3개
1. **branch zeroing**: trajectory 를 끄면 LOSO PS 가 0.348 → 0.833, QS 가 0.546 → 0.686 으로
   회복되고 seen 은 0.818 → 0.406 으로 무너진다.  A3 의 LOSO 실패는 trajectory branch 에서 온다.
2. **층 occlusion**: 1~8층은 ΔAUROC ≈ 0, 9~12층 블록 제거만으로 LOSO 3 fold 가 모두 회복
   (+0.454 / +0.173 / +0.102)되고 seen 은 −0.476.  유해 신호의 깊이가 특정된다.
3. **A3 전이 행렬**: 대각 0.921 대 비대각 0.478.  같은 아키텍처가 within-source 는 A0 보다
   잘 맞히고 cross-source 는 우연 이하로 떨어진다.  A0 는 비대각 0.635 로 전이된다.

## 16. 다음 architecture 변경 제안 (아직 적용하지 않음)
아래는 제안일 뿐이며 이번 phase 에서 구현·채택하지 않았다.

1. **깊이 범위 제한** — 9~12층 C 를 A3 입력에서 빼거나 별도 branch 로 분리.
   occlusion 이 직접 가리키는 최소 변경이다.
2. **크기 정규화(§13 N1/N2)** — `LayerNorm(C_lk)` 또는 `C_lk / ‖C_lk‖`.
   gate 는 미충족이지만 (a)가 성립하고 문제 층과 일치하므로 1순위 진단 후보다.
3. **branch 게이팅** — attribution branch 를 기본으로 두고 trajectory 기여를 학습된
   스칼라로 제한.  현재 fusion 은 두 branch 를 1:1 로 받는다.
4. **length confound 통제** — 조건 D 가 PS 에서 0.788 이므로, 어떤 후속 실험이든
   길이 대조군을 함께 보고해야 한다.

세 dataset 은 이미 개발·진단에 쓰였으므로 최종 OOD 주장은
새로운 external benchmark 와 post-freeze 평가로 따로 검증해야 한다.
