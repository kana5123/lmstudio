## 15. 최종 CASE 판정

**주 판정: CASE D1-B — LATE TRAJECTORY CAUSES NEGATIVE TRANSFER**
**동시 성립: CASE D1-C — TRAJECTORY ADDS NO OOD VALUE**
**기각: CASE D1-D (길이로 설명되지 않음), CASE D1-A, CASE D1-E**

근거:
- D1-B: V3(LATE)가 V2(EARLY)와 **seen 에서 동일**(0.8454 대 0.8454, macro 0.8766 대 0.8686)
  하면서 LOSO WJ −0.070(CI<0 4/5), PS −0.202(CI<0 5/5).  V2 가 V1 보다 세 fold 모두 개선
  (+0.042 / +0.081 / +0.103).  후기 층이 source-conditioned shortcut 을 만든다는 D0 진단이
  **처음부터 층을 제한한 재학습에서도 재현**됐다.
- D1-C: 그럼에도 V2 는 V0 를 넘지 못한다.  PS −0.280(5/5), QS −0.131(5/5) 로 **유의하게 나쁘고**
  WJ 만 +0.044(3/5).  L1~L8 궤적에 source 를 넘는 재사용 가능한 신호가 확인되지 않았다.
- D1-D 기각: 길이 매칭에서 length-only AUROC 가 0.501~0.518 로 신호가 제거됐는데도
  같은 패턴이 유지된다(seen V2−V0 는 매칭에서 오히려 +0.184 로 커진다).
- D1-E 기각: D0 의 occlusion 방향(후기 층 제거 → OOD 개선)이 재학습에서 재현됐다.
  다만 크기는 훨씬 작다(occlusion 은 PS +0.454, 재학습은 +0.081).  D0 결과를 단순 층 인과로
  과대 해석하면 안 된다는 점은 남는다.

## 16. 다음 단계 제안 하나
**A0(최종 attribution)를 기본 예측기로 두고, trajectory 를 보조 입력으로만 쓰되
cross-source validation 에서 그 기여를 게이팅하는 구조를 검증한다.**
근거: V0 만이 LOSO 세 fold 에서 0.5 를 넘고(0.511 / 0.707 / 0.704), 임계 전이도 V0 만
성립한다(실제 TP 손실 5.3~5.5% 대 나머지 17~72%).  현재 fusion 은 두 branch 를 1:1 로 받는다.
