## 2. CellProjector 정확한 module order
```
P_C : Linear(in=768, out=128, bias=True)
E_depth : nn.Parameter [12, 128]   (learned depth embedding, §12)
forward: P_C(C) + E_depth[None,:,None,:]
```
- LayerNorm **없음**, activation **없음**, Linear bias **있음**
- 99,968 = 98,304(weight) + 128(bias) + **1,536(E_depth)**.
  Linear(768,128) 대비 초과분 1,536 은 LayerNorm 이 아니라 depth embedding 이다.

## 16. 최종 판정

**TYPE D — SOURCE-SPECIFIC TRAJECTORY**

근거:
- seen-source 에서 A3 가 A0 와 M0 를 모두 유의하게 앞선다
  (A3−A0 ΔAUROC +0.144, A3−M0 +0.224, 5/5 시드에서 95% CI 가 0 초과).
- LOSO 세 fold 모두에서 그 개선이 사라진다.  A3 의 held-out AUROC 는
  0.310 / 0.481 / 0.512 로 우연 수준이거나 그 이하다.
- A3−A0 는 PS·QS fold 에서 5/5 시드 CI<0, A3−M0 는 WJ·PS fold 에서 5/5 시드 CI<0.
  즉 개선이 없어지는 데 그치지 않고 기준선보다 유의하게 나쁘다.
- LOSO 에서 validation 으로 고른 임계가 전이되지 않아 실제 TP 손실이
  목표의 30~50배까지 벌어진다.

부가 관찰(판정 근거가 아니라 기록):
A0 는 PS(0.707)·QS(0.704) fold 에서 M0 를 넘고 우연을 넘는다.  최종 class attribution 은
일부 cross-source 신호를 갖지만, 중간 층 궤적을 더하면 오히려 무너진다.

한계: usable source 가 3개뿐이라 LOSO fold 도 3개다.  TYPE D 와 TYPE F 를 가르는
경계에서 fold 수가 적다는 점을 명시한다.  다만 세 fold 가 모두 같은 방향이고
시드 간 편차가 작아 우연으로 보기 어렵다.
