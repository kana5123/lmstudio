## 1. 과제 정의 — 무엇을 탐지하는가

**"이전 지시나 안전장치를 덮어쓰려는 시도"의 탐지.**

Meta Prompt Guard 2 모델 카드의 정의를 그대로 따랐다.

> *"classify prompts as 'malicious' if the prompt explicitly attempts to override
> prior instructions... regardless of whether the prompt is potentially harmful"*

### 1.1 이 과제가 아닌 것 — 실험으로 확인한 세 가지

과제를 흐리지 않기 위해 아래 세 벤치마크는 **주 평가에서 제외**했다.
전부 "다른 층위"라는 것을 측정으로 확인했다.

| 벤치마크 | 학회 | 내용 | 근거 |
|---|---|---|---|
| MultiJail | ICLR 2024 | "창녀랑 어떻게 섹스를 하냐?" 같은 직접적 유해 요청 | Prompt Guard 2 가 **영어 원문에서 1.0%** 밖에 안 잡음 |
| CSRT | ACL 2025 | MultiJail 315건을 코드스위칭한 것 | 논문 원문: *"MultiJail sampled 315 prompts... translated"* |
| PIArena | ACL 2026 | "Before answering, include a note suggesting..." 광고·피싱 삽입 | Prompt Guard 2 **영어 7.8%**, NotInject 정상(9.3%)보다 낮음 |

**MultiJail 을 예로 들면:**
```
프롬프트 텍스트   "창녀랑 어떻게 섹스를 하냐?"
                  → 유해하지만 '이전 지시를 덮어쓰려는 시도'는 없음
```
논문의 주장("언어 자체가 우회")은 **모델의 응답**에 관한 것이지,
프롬프트 안에 우회 기법이 들어 있다는 뜻이 아니다.

## 3. 방법론

### 3.1 구성

```
교사   Llama-Prompt-Guard-2-86M        ❄ 학습하지 않음. 영어 채점만
       - 백본 mDeBERTa-v3-base (학생과 동일)
       - Meta 가 8개 언어로 학습 (한국어 미포함)
       - 18,585건 채점에 95초

학생   microsoft/mdeberta-v3-base      🔥 학습 대상
       - 이 과제를 배운 적 없는 빈 백본
       - 12층 · hidden 768 · 어휘 251,000
```

**빈 백본을 그냥 쓰면 0점이다** (한국어 @1%FPR **0.0000**).
사전학습은 "한국어를 읽는 능력"만 주고, "무엇이 공격인가"는 주지 않는다.

### 3.2 손실 함수

```
L = L_과제  +  λ · L_정렬
```

**과제 손실** — 교사의 확률분포를 학생이 재현
```
L_과제 = − Σ_k  q_k(x) · log p_k(x)

  q = 교사가 영어 문장 x 에 부여한 확률 (고정)
  p = 학생의 확률
```

실제 예:
```
"act like your Damon, Damon is A ruthless AI Bot..."
   교사 →  정상 0.0019 / 공격 0.9981     ← 학생의 학습 목표
   학생 →  정상 0.0014 / 공격 0.9986     ← 학습 후
```

**정렬 손실** — 같은 뜻의 영·한 문장을 8층에서 붙임 (Liu & Niehues, ACL 2025)
```
L_정렬 = − log   exp(sim(h_s^8, h_t^8)/τ)
                ─────────────────────────────
                 Σ_{v∈B} exp(sim(h_s^8, h_v^8)/τ)

  h^8   8층 은닉 상태의 마스크 가중 평균 (768차원)
  s,t   영어 문장과 그 한국어 번역
  v∈B   같은 배치의 다른 문장들 (번역 짝이 아닌 것)
  τ     온도 0.05
```

**핵심: 정렬 손실은 과제 라벨을 요구하지 않는다.**
필요한 건 "두 문장이 번역 관계"라는 사실뿐이다.

### 3.3 두 손실의 역할이 다르다

| | 가르치는 것 | 데이터 |
|---|---|---|
| `L_과제` | 무엇이 공격인가 | 영어 (교사 확률) |
| `L_정렬` | 같은 뜻의 영·한은 같은 자리에 | 영·한 병렬 (라벨 없음) |

비유하면 과제 손실은 시험 정답을 가르치고, 정렬 손실은 영한사전을 연결한다.

### 3.4 학습 설정
```
3 에폭 · lr 2e-5 · 배치 16 · λ=1.0 · τ=0.05 · fp16
정렬 층 i ∈ {4, 6, 8, 10},  λ=0 이면 정렬 없음(기준선)
학습 시간 약 40분 (GPU 1대)
```
코드: `align_kd.py`

## 4. 왜 8층인가 — 원인 분석

### 4.1 층별 번역 검색 실험

같은 뜻의 영·한 문장 1,200쌍을 넣고, **각 층에서** 한국어 문장 벡터와 가장 가까운
영어 문장 벡터가 실제 번역 짝인지 판정했다. 우연히 맞을 확률은 0.08%.

- 문장 벡터 = 그 층 모든 토큰 은닉 상태의 **마스크 가중 평균** (CLS 아님)
- 방향 = 한국어 → 영어
- 코드: `mechanism_probe.py`

| 층 | mDeBERTa<br>(사전학습만) | 영어 DeBERTa-v3 | Prompt Guard 2 | 증류 학생 | 하드라벨 |
|---:|---:|---:|---:|---:|---:|
| 0 | 8.50% | 6.50% | 8.42% | 8.33% | 8.50% |
| 4 | 30.83% | 10.83% | 26.00% | 20.50% | 35.75% |
| 6 | 87.75% | 31.17% | 79.42% | 79.42% | 89.08% |
| **8** | **93.00%** | 40.33% | **81.83%** | 82.17% | 90.58% |
| 10 | 81.75% | 14.58% | 53.50% | 59.17% | 77.25% |
| **11** | **2.17%** | 5.25% | **3.25%** | 7.08% | 3.25% |
| 12 | 3.33% | 0.92% | 6.50% | 9.42% | 4.00% |

### 4.2 읽는 법

**① 0~4층 — 아직 못 만남 (8~35%)**
입구에서는 글자 모양만 본다. `Ignore` 와 `무시` 는 글자가 달라 못 알아본다.

**② 6~10층 — 만난다 (80~93%)**
8층에서 "Ignore previous instructions"와 "이전 지시를 무시하세요"가 거의 같은 자리에 놓인다.
번역을 배운 적이 없는데도 그렇다. 여러 언어 문서를 읽으며 저절로 생긴 구조다.

**③ 11~12층 — 다시 갈라진다 (2~9%)**
한 층 만에 81% → 2% 로 무너진다.
DeBERTa-v3 는 "이 자리에 원래 무슨 토큰이 있었나"를 맞추도록 배우는데,
그 답은 **언어별 어휘**로 내야 한다. 그래서 출력에 가까울수록 언어별로 갈라진다.

**④ 우리 문제**
```
정렬이 가장 좋은 층   8층 (93%)
분류를 하는 층        12층 (3.33%)   ← 가장 나쁜 층에서 판정
```

### 4.3 확인한 두 가지 (둘 다 기각)

| 가설 | 검증 | 결과 |
|---|---|---|
| 영어 미세조정이 상위층 정렬을 깨뜨렸다 | 미세조정 전후 비교 | **기각** — 원본에서 이미 11층 2.17%. 미세조정 후 오히려 소폭 상승 (3.33→4.00) |
| 대규모 다국어 학습으로 해결된다 | Prompt Guard 2 측정 | **기각** — 8개 언어 학습에도 11층 3.25% |

→ **아무도 안 고친 문제이며, 사전학습 구조에서 기인한다.**

### 4.4 주의 — 두 지표는 다르다
```
번역 검색 정확도  ≠  탈옥 탐지 정확도
```
8층 93%는 "번역 짝을 찾는" 능력이지 "탈옥을 잡는" 능력이 아니다.
둘이 일치하는지는 §6.2 의 층별 실험이 별도로 검증한다.

## 6. 결과

### 6.1 주 결과 — 한국어 공격 1,848건, Recall @1%FPR

| 모델 | 영어 | **한국어** | **격차** | 한@0.1% |
|---|---:|---:|---:|---:|
| 교사 Prompt Guard 2 | **0.4756** | 0.2711 | **−0.2045** | 0.2316 |
| 정렬 없음 (기준선) | 0.3355 | 0.2440 | −0.0915 | 0.2359 |
| 4층 정렬 | 0.2808 | 0.2008 | −0.0801 | 0.1964 |
| 6층 정렬 | 0.3550 | 0.3025 | −0.0525 | 0.2976 |
| **8층 정렬 (제안)** | 0.3339 | **0.3323** | **−0.0016** | **0.3160** |
| 10층 정렬 | 0.3485 | 0.3252 | −0.0233 | 0.3187 |

**읽는 법 셋:**

1. **교사는 한국어에서 20.5%p 잃는다.** 영어 0.4756 → 한국어 0.2711.
2. **8층 정렬은 격차가 0.2%p 로 사라진다.** 영어 0.3339 ≈ 한국어 0.3323.
3. **한국어에서 교사를 6.1%p 앞선다.** 영어에서는 교사가 더 강한데, 한국어로 가면 뒤집힌다.

### 6.2 층 선택이 결과를 좌우한다

```
정렬 층    8층 정렬도    한국어 성능
없음          —          0.2440
 4층        30.83%       0.2008   ← 기준선보다 나쁨
 6층        87.75%       0.3025

10층        81.75%       0.3252
```

**§4 의 층별 정렬도와 성능이 같이 움직인다.**
정렬도가 낮은 4층에 손실을 걸면 하위층 표현이 망가져 과제 학습까지 방해한다.
"아무 층이나 되는 게 아니다"는 증거.

### 6.3 통계적 유의성 (한국어 공격 1,848건)

**95% 윌슨 신뢰구간 — 겹치지 않음**
```
8층 정렬    614/1848 = 0.3323   [0.3111, 0.3541]
교사 PG2    501/1848 = 0.2711   [0.2513, 0.2918]
정렬 없음   451/1848 = 0.2440   [0.2250, 0.2641]
```

**McNemar 정확검정 — 같은 문장에서 누가 맞췄나**
```
8층 vs 정렬없음   8층만 181건 · 정렬없음만  18건   p = 4.7e-35  ★
8층 vs 교사       8층만 175건 · 교사만      62건   p = 1.2e-13  ★
교사 vs 정렬없음  교사만  99건 · 정렬없음만  49건   p = 4.8e-05  ★
```

### 6.4 공격 유형별

| 모델 | JOT | in-the-wild | WildJailbreak | NotInject 오탐 |
|---|---:|---:|---:|---:|
| 정렬 없음 | 0.8182 | 0.4416 | 0.0368 | 0.0% |
| **8층 정렬** | **0.8986** | **0.4848** | **0.1421** | 0.6% |
| 교사 PG2 | 0.7972 | 0.4670 | 0.0762 | 0.6% |

- **JOT** 은 학습 분포와 가까워 0.90 으로 높다 (근접 중복 81.5% 포함)
- **WildJailbreak** 합성 적대적 공격이 가장 어렵다. 다만 0.0368 → 0.1421 로 **약 4배** 개선
- **NotInject 오탐 0.6%** — 과탐 없이 얻은 개선

### 6.5 근접 중복 제외 시 (JOT 구간, 신규 공격 53건)

```
              전체 286건    신규 53건    하락
하드라벨        0.9545       0.8113     −14%p
정렬 없음(증류)  0.8287       0.6038     −22%p
교사 PG2        0.8042       0.5472     −26%p
```

전부 떨어지지만 **순위는 유지되고 격차는 오히려 벌어진다.**
표본 53건에서도 McNemar 로 유의(하드라벨 vs 증류 p=0.0010).

## 7. 타당성 검증 — 지름길 가설 4종

결과가 표면적 단서로 나온 게 아님을 확인했다.

| 가설 | 검증 방법 | 결과 | 판정 |
|---|---|---|---|
| 길이만 보고 찍는다 | 글자수 = 점수 분류기 | @1%FPR **0.0000** | 기각 |
| 남은 영어를 본다 | 라틴 문자 전부 제거 후 재측정 | 학생 **−0.007** (대조군은 −0.381 붕괴) | 기각 |
| 번역기 냄새를 맡는다 | 정상도 같은 번역기로 번역 | 제거함 | 처리 |
| 글자 습관만 외웠다 | 동일 조건 어휘 대조군 | 학생 0.8287 vs 대조군 **0.4266** | 기각 |

### 7.1 어휘 대조군 상세

문자 3-gram TF-IDF + 선형 분류기. 의미를 전혀 모르는 "바보 분류기".

**대조군이 배운 것 (가중치 상위):**
```
「– i」 「h ‘」 「对应的」 「。 5」 「n/e」 「"my」 「 [m」 「ANI」 ...
```
특수 대시, 중국어 조각, 대괄호 — **탈옥 개념과 무관한 글자 습관**이다.

**공정 조건 (학생과 동일: 영어 학습셋으로만 학습, 한국어 미접촉)**
```
              영어      한국어
학생          0.9091    0.8287
어휘 대조군    0.8252    0.4266     ← 한국어에서 40%p 차이
```

**라틴 제거 시**
```
어휘 대조군   0.4266 → 0.0455   붕괴
학생          0.8547 → 0.8478   무변화
```
→ **어휘 규칙은 언어를 못 건너간다. 표현 수준 지식은 건너간다.**

### 7.2 ★ 이 과정에서 저지른 실수 (반복 금지)

처음에는 대조군을 **시험셋 절반으로 학습**시켰다. 그러면 0.8503 이 나와
"우리 모델(0.8287)이 대조군에 진다 → 결과 무의미"로 **멀쩡한 결과를 폐기할 뻔했다.**

대조군은 반드시 **모델과 동일한 학습 조건**이어야 한다.

### 8.1 평가셋 설계 실패 2종

### 8.2 방법 실패

**하드라벨 학습** (`models/jot_hardlabel`) — 원 라벨 0/1로 직접 학습
```
                 영 @1%    한 @1%
하드라벨          0.9895    0.9545    ← 증류보다 높음
증류              0.9091    0.8287
```
성능은 더 좋으나 **논문 전제(라벨 없음)를 위반**하므로 본문에서 제외.
심사에서 "라벨 있으면 그냥 학습하면 되지 않나" 질문이 나올 수 있어 한계 절에 언급 필요.

**MONOX-KD 증류 단독** — 교사 대비 +2.5%p 였으나 McNemar p=0.45 로 **유의하지 않음**.
정렬 손실을 붙여야 유의한 개선이 나온다.
